# Week 2: Tableau Dashboard Planning and Design Strategy

## Project Overview
This project builds on Week 1's Retail Sales Profitability Exploratory Data Analysis (EDA) using the Tableau Sample Superstore dataset.

The objective is to plan and develop an interactive dashboard that helps users understand sales performance, profitability, discount patterns, product categories, and regional differences.

## Dashboard Objectives
- Monitor key performance indicators (KPIs).
- Compare sales and profit across product categories and regions.
- Identify profitable and loss-making sub-categories.
- Explore the relationship between discounting and profitability.
- Analyse state-level profitability geographically.
- Enable interactive exploration through dashboard filters.

## Key Performance Indicators
- Total Sales
- Total Profit
- Total Orders
- Average Discount

## Visualisations
1. Sales and Profit by Category
2. Sales and Profit by Region
3. Discount vs. Profit
4. Profit by Sub-Category
5. State Profitability Map

## Interactive Features
The dashboard includes filters for Category, Segment, and Region to help users explore different parts of the dataset.

## Design Approach
The dashboard uses a KPI row, a main analytical chart area, and supporting geographic analysis. Consistent titles, readable labels, and colour encoding help users interpret the results.

## Tools
- Tableau
- Sample Superstore dataset

## Deliverables
- Dashboard planning and design document
- Interactive Tableau dashboard
- Dashboard screenshot

## Week 2 Outcome
The outcome is an interactive Tableau dashboard supported by a documented design strategy. The dashboard is intended to help users explore retail performance and identify areas requiring further investigation.
